# ✈️ Wandr AI – Intelligent Travel Concierge

Wandr AI is an AI-powered travel assistant that helps users discover destinations, generate personalized itineraries, explore live weather conditions, and interact with travel documents through an intuitive Streamlit interface.

## 🌟 Features

* 🤖 AI-powered travel recommendations and trip planning
* 🗺️ Personalized itinerary generation based on destination, budget, travel style, and interests
* 🌤️ Real-time weather information for destinations worldwide
* 📄 PDF document upload and question-answering support
* 💬 Interactive travel chatbot for instant travel assistance
* 🎯 Quick destination shortcuts for popular travel locations
* 📜 Search history and itinerary saving functionality
* 🌍 Dynamic destination-themed backgrounds

## 🛠️ Tech Stack

* **Frontend:** Streamlit
* **AI Model:** Groq (Llama 3.1)
* **Weather API:** OpenWeatherMap
* **Document Processing:** PyPDF2
* **Programming Language:** Python
